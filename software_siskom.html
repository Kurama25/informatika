Software (Perangkat Lunak)

Memahami bagaimana instruksi, program, dan data mengendalikan perangkat keras (hardware), mendukung pekerjaan pengguna (brainware), dan menjaga komputer tetap beroperasi secara optimal.

Pembaruan IBM & Microsoft (2026) Integrasi Hardware-Software Lisensi & Keamanan
1

Pengertian Software

Software (perangkat lunak) adalah kumpulan program, instruksi, dan data yang digunakan untuk mengatur komputer agar dapat menjalankan tugas tertentu.

Berbeda dengan hardware yang berupa komponen fisik, software tidak dapat disentuh secara fisik seperti keyboard, monitor, atau prosesor.

Menurut IBM: Software berisi instruksi atau program yang memberi tahu komputer apa yang harus dilakukan. Software memungkinkan hardware menjalankan berbagai fungsi sesuai kebutuhan pengguna.

Contoh Software Siswa

  • Windows Menjalankan dan mengelola sistem komputer
  • Microsoft Word Membuat dokumen & laporan
  • Google Chrome Membuka situs web & informasi
  • Canva Membuat desain grafis & poster
2

Hubungan Hardware, Software, & Brainware

1. Hardware

Perangkat Keras

Komponen fisik komputer yang menjalankan fungsi input, pemrosesan, output, dan penyimpanan.

Contoh: CPU, RAM, Keyboard, Monitor, SSD.

2. Software

Perangkat Lunak

Program dan instruksi yang mengatur sumber daya komputer serta membantu pengguna bekerja.

Contoh: Windows, Linux, Browser, Word.

3. Brainware

Pengguna / Manusia

Orang yang menggunakan, mengoperasikan, mengelola, atau mengembangkan sistem komputer.

Contoh: Siswa, Guru, Operator, Programmer.

3

Jenis-Jenis Software (Klasifikasi)

A. System Software (Perangkat Lunak Sistem)

Mengelola hardware dan menyediakan layanan dasar agar aplikasi lain dapat berjalan.

1. Sistem Operasi (OS)

Software utama yang mengelola sumber daya komputer (prosesor, memori, I/O, berkas, keamanan).

Windows: Komputer pribadi, lab sekolah.
Linux (Ubuntu): Server, edukasi, dev.
macOS: Perangkat Mac Apple.
Android: Smartphone & tablet.
*Dokumentasi Microsoft Jan 2026
2. Device Driver

Software penerjemah yang memungkinkan sistem operasi berkomunikasi dengan perangkat keras tertentu.

  • Driver Printer (cetak dokumen)
  • Driver Audio (suara/speaker)
  • Driver Grafis (kartu VGA)

Jika driver hilang, hardware bermasalah!

3. Firmware

Software tingkat rendah yang tertanam langsung pada ROM/memori nonvolatil perangkat keras.

  • BIOS / UEFI Motherboard
  • Firmware Router Wi-Fi
  • Firmware Printer

Melekat erat pada hardware, beda dari aplikasi biasa.

B. Application Software (Perangkat Lunak Aplikasi)

Dibuat khusus untuk membantu pengguna menyelesaikan pekerjaan tertentu secara langsung.

Pengolah Kata

Membuat & mengedit surat, laporan, makalah.

MS Word, Google Docs

Pengolah Angka

Mengolah rumus, perhitungan, tabel & grafik.

MS Excel, Google Sheets

Presentasi

Membuat slide visual menyampaikan informasi.

MS PowerPoint, Google Slides

Desain Grafis

Membuat poster, ilustrasi & memanipulasi gambar.

Canva, Photoshop, CorelDRAW

Browser Web

Aplikasi pembuka situs web (*bukan search engine).

Chrome, Firefox, Edge

Multimedia

Memutar, merekam, & mengedit media audio/video.

VLC Media Player, Video Editor

C. Programming Software (Perangkat Lunak Pemrograman)

Perangkat lunak yang digunakan oleh pengembang/programmer untuk menulis, menguji, dan merawat program.

Software / Alat Fungsi Utama Contoh Lengkap
Code Editor Tempat menulis dan mengelola baris kode program. Visual Studio Code
Compiler Menerjemahkan kode sumber secara keseluruhan menjadi kode mesin/eksekusi. GCC, javac
Interpreter Menerjemahkan & menjalankan kode baris demi baris. Python Interpreter
Debugger Membantu melacak dan menemukan kesalahan (bug) pada program. GDB, VS Code Debugger
Version Control Melacak riwayat perubahan kode & kolaborasi tim. Git

D. Utility Software (Perangkat Lunak Utilitas)

Membantu pemeliharaan, optimalisasi, pengelolaan, dan perlindungan sistem komputer.

Antivirus / Antimalware

Mendeteksi & menangani virus/malware. Contoh: Microsoft Defender.

Kompresi Berkas

Memampatkan ukuran atau mengekstrak arsip. Contoh: 7-Zip, WinRAR.

Backup Software

Salinan data cadangan untuk pemulihan. Contoh: Windows Backup.

Disk & File Management

Mengelola partisi memori & struktur folder. Contoh: File Explorer.

E. Embedded Software (Perangkat Lunak Tertanam)

Dirancang khusus untuk mengendalikan fungsi spesifik pada perangkat elektronik di luar komputer biasa.

Mesin Cuci Otomatis

Mengatur siklus bilas & putaran

Sistem Rem (ABS)

Mengendalikan pengereman kendaraan

Kamera Digital

Mengolah hasil jepretan sensor

Sensor IoT Smart Home

Merespons input suhu/gerak

Software Berdasarkan Cara Penggunaannya

A. Software Desktop

Offline Ready

Dipasang (diinstal) dan dijalankan secara lokal di komputer atau laptop.

Kelebihan: Tetap berjalan tanpa internet & memanfaatkan penuh performa fisik PC.
Keterbatasan: Makan ruang memori/storage & perlu instalasi manual.
Contoh: MS Word Desktop, VLC, VS Code.

B. Software Berbasis Web

Browser Based

Diakses melalui peramban (browser) web tanpa wajib menginstal aplikasi.

Kelebihan: Hemat storage, fleksibel di mana saja, mudah kolaborasi real-time.
Keterbatasan: Sangat bergantung pada kualitas koneksi internet.
Contoh: Google Docs web, Canva Web.

C. Software Cloud (SaaS)

Cloud Model

Memanfaatkan infrastruktur server cloud jarak jauh (Software as a Service).

*Catatan: Web App merujuk pada media aksesnya (browser), sedangkan Cloud merujuk pada model pemrosesan servernya.

Contoh: Google Workspace, Microsoft 365 Cloud.

D. Fitur Kecerdasan Artifisial (AI)

Smart Assist

AI bukan kategori terpisah, melainkan fitur pintar yang disematkan pada web/desktop app.

Hal Penting Diterapkan Siswa:

Periksa kembali hasil AI karena bisa salah (halusinasi). Jangan pernah memasukkan data rahasia/pribadi ke sistem AI!

Fungsi: Bantu draf poster, analisis data, terjemahan.

Instalasi, Lisensi, & Keamanan Software

1. Jenis Lisensi Software

Proprietary Hak cipta tertutup, diatur sepenuhnya oleh pemilik. (Contoh: MS Windows).
Open Source Kode sumber terbuka untuk dipelajari, diubah, & dibagikan. (Contoh: Linux).
Freeware Gratis dipakai, tapi belum tentu kode sumbernya boleh diubah.
Shareware / Trial Uji coba gratis dengan batasan waktu/fitur tertentu.

2. Steps Instalasi Aman

  1. Cek persyaratan spesifikasi sistem PC.
  2. Unduh dari **situs resmi** penyedia.
  3. Baca opsi & izin akses saat instalasi.
  4. Jalankan proses setup sampai selesai.
  5. Lakukan pembaruan (update) berkala.

3. Cyber Security Tips (CISA)

Kebiasaan Aman Menggunakan Komputer:

  • Hindari menunduh software **bajakan**.
  • Selalu perbarui OS & Browser untuk menutup celah keamanan (vulnerability).
  • Lakukan backup data penting ke media eksternal/cloud.
  • Hapus (uninstall) aplikasi tak terpakai secara benar.

Petunjuk Diskusi Mandiri (Klik untuk Jawaban Solutif)

1. Mengapa komputer yang sudah menyala belum tentu bisa digunakan untuk mengetik laporan?

Karena komputer baru menyediakan Sistem Operasi (System Software). Tanpa dipasang Application Software khusus pengolah kata (seperti MS Word atau LibreOffice Writer), komputer tidak memiliki instruksi spesifik untuk memproses pembuat dokumen.

2. Software apa yang diperlukan untuk membantu komputer berkomunikasi dengan printer?

Diperlukan Device Driver (Driver Printer). Driver bertindak sebagai penerjemah perintah dari Sistem Operasi agar dapat dipahami oleh perangkat keras printer.

3. Mengapa browser dan sistem operasi perlu diperbarui secara berkala?

Untuk menutup celah keamanan (bug/vulnerability), menambah dukungan standar web modern, serta menjaga kompatibilitas dengan aplikasi/fitur baru.

4. Apa langkah yang sebaiknya dilakukan jika aplikasi harus dipasang di komputer sekolah?

Melaporkan kepada teknisi/labkom (admin), mengunduh dari situs resmi, memeriksa kesesuaian lisensi (mengutamakan Open Source/Freeware legal), dan memindai installer dengan antivirus.
