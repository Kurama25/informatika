Apa itu Pseudocode?

Pseudocode adalah cara menuliskan langkah-langkah algoritma menggunakan bentuk yang menyerupai kode program, tetapi tetap menggunakan bahasa yang mudah dipahami manusia.

Pseudocode bukan bahasa pemrograman sehingga tidak dapat langsung dijalankan oleh komputer. Digunakan untuk merancang logika sebelum diterjemahkan ke Python, Java, PHP, atau JS.

Algoritma Pseudocode Program
2

Mengapa Menggunakan Pseudocode?

  • Merancang solusi secara sistematis sebelum membuat program.
  • Membuat logika program lebih mudah dipahami oleh tim.
  • Membantu menemukan kesalahan logika (bug) sebelum coding.
  • Bebas dari sintaks kaku bahasa pemrograman tertentu.
Hal Penting: Tidak ada aturan sintaks baku yang wajib! Yang terpenting adalah logikanya jelas, terurut, dan mudah dipahami.

Konsep Input–Process–Output

Pola paling mendasar yang perlu dikuasai dalam pemrograman:

1. Input
Data masukan (Contoh: harga, jumlah, nilai)
2. Process
Pengolahan data (Contoh: total ← harga × jumlah)
3. Output
Hasil pengolahan (Contoh: total harga, status lulus)
5

Percabangan (IF-ELSE)

Pengambilan keputusan berdasarkan kondisi

Ketika program harus memilih langkah berdasarkan kriteria tertentu (misal: Menentukan Kelulusan nilai >= 75).

START
INPUT nilai
Periksa kondisi:
IF nilai >= 75 THEN
OUTPUT "Lulus"
ELSE
OUTPUT "Tidak Lulus"
END IF
END

5 Aturan Penulisan Terbaik

Agar pseudocode mudah dibaca manusia & dipahami

1
Berurutan: Tuliskan langkah secara logis tanpa melompat-lompat.
2
Kata Kunci Jelas: Gunakan INPUT nilai daripada x ← ?.
3
Nama Variabel Bermakna: Gunakan harga, total daripada a, b.
4
Indentasi (Spasi): Berikan tab/spasi di dalam struktur blok IF atau FOR.
5
Fokus Logika: Jangan terlalu terikat sintaks kaku bahasa tertentu.
