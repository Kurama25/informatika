01

Berpikir Komputasional (Computational Thinking)

Computational Thinking (CT) adalah landasan cara berpikir sistematis untuk memahami masalah dan merancang solusi yang dapat dilaksanakan oleh manusia maupun komputer. Terdapat 4 pilar utama:

Dekomposisi

Memecah masalah besar dan rumit menjadi bagian-bagian yang lebih kecil dan mudah dikelola.

Pengenalan Pola

Mencari kesamaan, kecenderungan, atau pola yang berulang dari masalah sejenis.

Abstraksi

Fokus hanya pada informasi penting dan mengabaikan detail irrelevant yang tidak dibutuhkan.

Algoritma

Menyusun langkah-langkah penyelesaian secara sistematis dan logis dari awal hingga akhir.

Contoh Penerapan CT: Penentuan Kelulusan Siswa

Dekomposisi:

Mengetahui nilai siswa → Menentukan batas KKM → Membandingkan nilai → Menentukan status kelulusan.

Pengenalan Pola:

Setiap siswa punya nilai ujian. Jika Nilai ≥ Batas (75) → Lulus. Jika kurang → Tidak Lulus.

Abstraksi:

Abaikan warna baju, nomor sepatu, atau tempat tinggal. Cukup ambil data Nilai Ujian dan Batas Kelulusan.

Algoritma:

1. Masukkan Nilai; 2. Cek apakah Nilai ≥ 75; 3. Jika ya, cetak "Lulus"; 4. Jika tidak, cetak "Tidak Lulus".

02

Apa itu Algoritma & Konsep IPO?

Algoritma adalah urutan langkah logis dan sistematis untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu. Algoritma dapat dituliskan dalam bahasa sehari-hari, pseudocode, maupun diagram flowchart.

5 Ciri Algoritma yang Baik:

1. Memiliki Input Menerima nol atau lebih data masukan.
2. Memiliki Output Menghasilkan minimal satu luaran/hasil.
3. Langkah Jelas (Definiteness) Tidak menimbulkan arti ganda (ambigu).
4. Ada Akhir (Finiteness) Proses akan berhenti setelah sejumlah langkah.
5. Dapat Dilaksanakan (Effectiveness) Setiap instruksi harus wajar dan nyata dapat dikerjakan.

Model IPO (Input-Process-Output)

Prinsip dasar pengolahan data pada sistem komputer.

Input Panjang = 10, Lebar = 5
Process Luas = Panjang × Lebar
Output Luas = 50

03

Mengenal Pseudocode & Kata Kunci Utama

Pseudocode (semu / kode semu) berfungsi sebagai jembatan antara logika pemikiran manusia dan kode pemrograman sebenarnya.

START / END Awal & Akhir
INPUT / READ Menerima Data
OUTPUT / PRINT Menampilkan Hasil
← (Penugasan) Simpan nilai variabel
IF - ELSE Percabangan Kondisi
FOR / WHILE Perulangan (Looping)

Sequence (Struktur Runtutan)

Instruksi dijalankan berurutan baris demi baris dari atas ke bawah tanpa lompatan.

START
    INPUT panjang
    INPUT lebar
    luas ← panjang * lebar
    OUTPUT luas
END

Selection (Struktur Percabangan / Decision)

Memilih jalur tindakan berdasarkan kondisi BENAR (True) atau SALAH (False).

START
    INPUT nilai
    IF nilai >= 75 THEN
        OUTPUT "Lulus"
    ELSE
        OUTPUT "Tidak Lulus"
    END IF
END

Looping (Struktur Perulangan)

Mengeksekusi blok perintah berulang kali selama kondisi tertentu terpenuhi.

START
    FOR i ← 1 TO 5 DO
        OUTPUT i
    END FOR
END

Simbol-Simbol Dasar Flowchart

Flowchart adalah penggambaran visual logika algoritma menggunakan diagram simbol standar yang dihubungkan oleh panah alur (flowline).

Terminal
Bentuk: Oval

Menandai awal (Start) atau akhir (End) dari suatu algoritma.

Input / Output
Bentuk: Jajar Genjang

Menerima masukan data atau menampilkan hasil/keluaran.

Process
Bentuk: Persegi Panjang

Menyatakan operasi aritmatika atau pengolahan data.

Decision
Bentuk: Belah Ketupat

Pengambilan keputusan dengan opsi Ya/Tidak (True/False).

Flowline
Bentuk: Garis Panah

Menunjukkan arah aliran langkah demi langkah.

Studi Kasus Terintegrasi: Kasir Kantin Sekolah

Mari kita pelajari alur lengkap pemecahan masalah secara terintegrasi—mulai dari analisis Computational Thinking (CT) & IPO, penulisan Algoritma Naratif (kalimat deskriptif), penyusunan Pseudocode, hingga pembuatan Flowchart.

1

Analisis CT & IPO

Masalah: Menghitung total transaksi belanja pembeli di kantin sekolah.

Dekomposisi: Meminta data harga → Meminta jumlah barang → Mengalikan → Menampilkan total.

Abstraksi: Abaikan nama pembeli, merek makanan, atau warna piring.

Input: harga, jumlah
Process: total = harga × jumlah
Output: total pembayaran
Tahap 1: Formulasi Ide
2

Algoritma Naratif

Penulisan langkah sistematis dalam bahasa sehari-hari (kalimat deskriptif):

  1. Mulai proses transaksi kasir.
  2. Masukkan harga satu unit barang.
  3. Masukkan jumlah barang yang dibeli.
  4. Hitung total bayar dengan mengalikan harga dengan jumlah.
  5. Tampilkan hasil total pembayaran ke layar.
  6. Selesai.
Tahap 2: Bahasa Sehari-hari
3

Pseudocode

Penulisan terstruktur menggunakan kata kunci terstandar:

START
    INPUT harga
    INPUT jumlah

    total ← harga * jumlah

    OUTPUT total
END
Tahap 3: Struktur Kode Semu

Pengembangan Studi Kasus: Menghitung Diskon Kantin (Percabangan / Selection)

Kantin memberikan diskon sebesar Rp 5.000 jika total belanja mencapai Rp 50.000 atau lebih.

Algoritma Naratif (Kalimat Deskriptif)
  1. Mulai transaksi.
  2. Masukkan total belanja awal.
  3. Periksa apakah total belanja ≥ 50.000.
  4. Jika YA, hitung bayar = total belanja - 5.000.
  5. Jika TIDAK, maka bayar = total belanja tanpa potongan.
  6. Tampilkan total bayar akhir.
  7. Selesai.
Pseudocode (Selection) 
START
    INPUT total_belanja
    IF total_belanja >= 50000 THEN
        bayar ← total_belanja - 5000
    ELSE
        bayar ← total_belanja
    END IF
    OUTPUT bayar
END

Kesalahan yang Sering Terjadi pada Siswa Kelas X

1. Menganggap Pseudocode Adalah Kode Bahasa Pemrograman

Pseudocode tidak bisa langsung dieksekusi oleh komputer (seperti Python/Java). Pseudocode ditulis untuk dibaca manusia sebagai rancangan.

2. Menukar Input dan Output

Misalnya: Menganggap luas = panjang * lebar sebagai Input, padahal luas adalah Output dan panjang, lebar adalah Input.

3. Lupa Menambahkan Panah Alur (Flowline)

Setiap simbol dalam flowchart wajib dihubungkan oleh panah penunjuk arah dari Start sampai ke End.

4. Simbol Decision Tanpa 2 Cabang Keputusan

Simbol belah ketupat (Decision) wajib memiliki minimal dua jalur cabang berlabel YA/TIDAK (True/False).
